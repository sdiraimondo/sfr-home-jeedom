# Plugin SFR Home pour Jeedom

Ce plugin permet de connecter et contrôler vos équipements SFR Home dans Jeedom.

## Fonctionnalités

- Découverte automatique des équipements SFR Home
- Contrôle des prises connectées
- Gestion de l'alarme SFR Home
- Capteurs (ouverture, mouvement, fumée, température/humidité)
- Volets roulants
- Lumières
- Caméras SFR Home

## Configuration

1. Installer le plugin
2. Configurer vos identifiants SFR dans la configuration du plugin
3. Activer le démon ou utiliser le cron
4. Lancer la synchronisation

## Authentification

Le plugin utilise le même système d'authentification SSO que l'application SFR Home, avec gestion automatique des cookies.
